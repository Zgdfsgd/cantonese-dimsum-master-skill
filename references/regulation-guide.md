# 法规速查与预制识别标准

---

## 一、《广州早茶传承保护规定》核心条款

2026年1月21日经广州市十六届人大常委会第四十七次会议表决通过，2026年5月1日起施行。全国首部早茶专项法规。

### 5项硬性规定

#### 1. 传统现制24小时时效标准
以传统方式现场制作的早茶食品，从食品制成到提供食用时间不超过24小时。因传统技艺制作需要超过24小时的，由广州市餐饮相关行业协会等予以明确。

#### 2. 茶位费须供5种茶
广州早茶经营者收取茶位费的，应当提供红茶、绿茶、乌龙茶、普洱茶、菊花茶供消费者从中选择，并做好相关茶饮服务。不得缩减品类、以次充好。茶位费包含续水、清洗茶具等基础服务，不得额外收取续水费、茶具费。

#### 3. 必须明示制作方式
经营者须向消费者明示早茶食品以"传统方式现场制作"或者"非传统方式制作"。所有预制、速冻、半成品加工的点心，必须在菜单、价签上显著标注"非传统制作"，字体清晰易识别，不得模糊标注、隐瞒不报。

#### 4. 差异化定价
同一款点心，传统现制与非传统预制可实行不同价格，消费者可根据需求自主选择。

#### 5. 透明厨房要求
提供传统现制点心的茶楼，需通过透明厨房、开放式厨房、视频监控公示等方式，向消费者展示点心制作过程。

### 违规处罚
对隐瞒点心制作方式、强制收取茶位费、价格不透明、后厨不达标等违规行为，依法责令整改、罚款，情节严重的列入失信名单。

## 三、预制识别六维判断法

| 维度 | 手工点心 | 预制点心 |
|------|---------|---------|
| 外观 | 形态自然，略有差异，手工痕迹可见 | 大小一致，过于规整，模具感强 |
| 口感 | 皮薄馅鲜，有层次感，汁水丰富 | 皮厚馅干，味道单一，口感发柴 |
| 温度 | 上桌时热气腾腾，蒸汽明显 | 温温的，不够热，缺乏蒸汽 |
| 等待 | 现点现蒸，需等5-10分钟 | 即点即上，无需等待 |
| 价格 | 略贵，但物有所值 | 便宜，但品质一般 |
| 厨房 | 透明/开放式厨房，可见制作过程 | 封闭式后厨，无法观察 |

## 四、半成品 vs 预制菜 区分

**半成品≠预制菜**：
- 中央工厂统一处理食材、制作半成品，配送到门店后由师傅现场调味、拌馅、包制成品，24小时内卖完，属于"手工制作点心"
- 预制菜：工厂完成全部制作流程，门店仅需加热即售

**判断标准**：
- 门店是否有师傅现场包制/调味 → 有=半成品（手工） / 无=预制
- 是否在24小时内现制现售 → 是=手工 / 否=预制
- 是否有透明厨房展示 → 有=更可信 / 无=需警惕

## 五、避坑技巧

1. **问服务员**："哪些是现做的？"——根据新规，服务员必须如实告知
2. **观察厨房**：透明/开放式厨房更可信，封闭式后厨需警惕
3. **经典点心优先手工**：虾饺、烧卖、凤爪、肠粉等经典点心，手工与预制差异最大，优先选手工
4. **看外观**：过于规整、大小完全一致的慎选
5. **摸温度**：上桌不够热的慎选
6. **看等待时间**：即点即上的蒸点大概率是预制
7. **看菜单标注**：根据新规，茶楼必须标注"传统方式现场制作"或"非传统方式制作"

## 八、消费者维权指引

根据《广州早茶传承保护规定》：
- 发现价格不一致、未公示收费项目 → 12345政务服务热线投诉举报
- 发现预制冒充现制、未标注制作方式 → 向市场监管部门投诉
- 被强制收取茶位费但未提供相应服务 → 向市场监管部门投诉
- 发现后厨不达标 → 向市场监管部门投诉

## 九、法规意义

《广州早茶传承保护规定》的核心是规范而非涨价，保护而非限制：
- 对消费者：茶位费不再糊涂收、点心不再被"忽悠"、消费全程透明
- 对合规茶楼：打击低价劣质预制冒充现制的乱象，减少不公平竞争
- 对广府文化：以立法形式守护早茶非遗技艺，避免传统风味被工业化侵蚀
