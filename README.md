## 功能概览

| 能力 | 说明 |
|------|------|
| 📋 智能点单 | 输入人数+预算+口味+场景 → 最优点单方案 |
| 🏠 茶楼推荐 | 30间实体茶楼数据，按城市/预算/场景匹配 |
| 🍵 茶文化科普 | 茶叶选择、历史典故、非遗知识 |
| 🙏 饮茶礼仪速查 | 文化科普，了解即可，不强制 |
| ⚠️ 预制菜避坑 | 法规依据+六维识别法+手工推荐 |
| ➕ 加单/打包策略 | 续点推荐+行街指南 |

## 法规支撑

基于《广州早茶传承保护规定》（2026年5月1日施行，全国首部早茶专项法规）：
- 传统现制24小时时效标准
- 茶位费须供5种茶
- 必须明示制作方式
- 差异化定价
- 透明厨房要求
